micro-flow — ETL pipeline demo

A batch job on the server: extract a CSV, profile it, clean it in batches, stop at a quality gate if too much is junk, then upsert it into a shared warehouse in chunks that retry when a write fails. Run the same file twice and nothing changes the second time.

Source CSV order_id, date, customer_email, country, amount, currency
