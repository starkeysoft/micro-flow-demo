micro-flow — demos

  • box-tour A box tours the arena using Step, LoopStep, DelayStep and ConditionalStep.
  • pokemon-party Fetches six random Pokémon from PokeAPI into flip cards using Step, ConditionalStep and a for_each LoopStep.
  • launch-control A rocket launch that uses nearly all of micro-flow: switch/case, break and skip, while and generator loops, retries, timeouts, a nested workflow, pause/resume, checkpoints that survive a reload, and an observer tab fed by cross-tab events.
  • robot-builder Build a robot's program from blocks. The program is a live micro-flow Workflow edited through its step API, with nested workflows in loops, if/else and switch, all the condition operators, and a run history from sessions.
